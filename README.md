# nunchimangchi-dev.github.io

Portfolio landing page tying together
[unbrokerrdd](https://github.com/nunchimangchi-dev/unbrokerrdd) and
[droppdd](https://github.com/nunchimangchi-dev/droppdd), with
[skyrise](https://github.com/nunchimangchi-dev/skyrise) as the supporting
dev-environment infrastructure. Built specifically because those repos,
referenced by name on a resume and on LinkedIn, needed one place that
explains what each is and why, rather than leaving a reader to piece it
together from separate repos.

Plain static HTML/CSS, no build step, no framework, served directly by
GitHub Pages at [nunchimangchi.com](https://nunchimangchi.com).

Content is written directly, grounded in each project's actual
README/commit history and kept in sync with the canonical LinkedIn
descriptions, not generated speculatively.
