# nunchimangchi-dev.github.io

Portfolio landing page tying together [skyrise](https://github.com/nunchimangchi-dev/skyrise),
[droppdd](https://github.com/nunchimangchi-dev/droppdd), and
[DATABROKER.deep](https://github.com/nunchimangchi-dev/DATABROKER.deep) —
built specifically because those three repos, referenced by name on a
resume, needed one place that explains what each is and why, rather than
leaving a reader to piece it together from separate repos.

Plain static HTML/CSS, no build step, no framework — served directly by
GitHub Pages at [nunchimangchi-dev.github.io](https://nunchimangchi-dev.github.io).

Content (what each project is, the AI-collaboration process description)
was written directly, grounded in each project's actual README/commit
history — not generated speculatively. A cosmetic design pass may follow
via the same Gemini workflow used on droppdd (see that repo's
`docs/GEMINI-DESIGN-PASS-PROMPT.md` for the pattern).
