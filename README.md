# nunchimangchi-dev.github.io

Portfolio landing page tying together
[unbrokerrdd](https://github.com/nunchimangchi-dev/unbrokerrdd) and
[droppdd](https://github.com/nunchimangchi-dev/droppdd). Built because those
projects are easier to understand together than as separate repositories —
one place that explains what each is and why, rather than leaving a reader to
piece it together.

Plain static HTML/CSS, no build step, no framework, served directly by
GitHub Pages at [nunchimangchi.com](https://nunchimangchi.com).

Content is written directly, grounded in each project's actual README and
commit history, not generated speculatively.
